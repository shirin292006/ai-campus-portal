# AI Campus Portal 🎓🤖

## Problem Statement  
Students often struggle to navigate college resources, access academic information, and find the right support for their studies. Existing portals are either too cluttered, outdated, or not personalized enough.  
Our goal is to create an **AI-powered Campus Portal** that makes accessing academic, administrative, and support services simple, smart, and interactive.

---

## Current Progress 🚧  
- ✅ Initial Next.js project structure completed  
- ✅ Admin and Student dashboards created  
- ✅ Core UI components integrated (cards, forms, buttons, widgets)  
- ⏳ Pending integration of backend APIs for real data  
- ⏳ AI chatbot for instant student support  
- ⏳ Deployment to cloud hosting (Vercel/GitHub Pages)

---

## How Our Prototype Solves the Problem 💡  
- Provides a **centralized platform** for students and admins  
- Features an **AI chatbot widget** for quick queries  
- Clean and modern **dashboard UI** for navigation  
- Scalable architecture built with **Next.js + TypeScript**  

---

## Technologies & Tools ⚙️  
- **Next.js (React + TypeScript)** – frontend framework  
- **Tailwind CSS** – UI styling  
- **ShadCN UI Components** – ready-to-use design system  
- **Node.js & npm** – package and script management  
- **Vercel (planned)** – deployment platform

   npm install
3. Start the development server:
   npm run dev
